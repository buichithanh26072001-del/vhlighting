script.js
img/
  thanhray.jpg
  amtran.jpg
  ledthanh.jpg
  nguonled.jpg
  trangtri.jpg
  phukien.jpg

Ý nghĩa ảnh:
- thanhray.jpg  = Đèn ray nam châm / thanh ray
- amtran.jpg    = Đèn âm trần / panel
- ledthanh.jpg  = Led thanh nhôm
- nguonled.jpg  = Nguồn LED
- trangtri.jpg  = Đèn trang trí
- phukien.jpg   = Phụ kiện LED
- quattran.jpg  = Quạt trần

Kích thước ảnh khuyên dùng:
- 1200 x 800 px
- Đuôi .jpg
- Dung lượng dưới 500KB/ảnh

Lưu ý quan trọng:
- Tên thư mục phải là img
- Tên ảnh viết thường, không dấu, không khoảng trắng
- Upload lên Netlify bằng cách kéo cả thư mục này, không kéo riêng file index.html
